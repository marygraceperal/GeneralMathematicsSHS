1. Understanding domain and range

Domain is the set of all allowable input values (usually x). Range is the set of all possible output values (usually y or f(x)).

From a graph: read the domain from left to right and the range from bottom to top. Identify the values actually reached by the graph.

Ways to write domain and range

NotationExample: x is at least 3
Inequalityx ≥ 3
Interval[3, ∞)
Set-builder{x ∈ ℝ | x ≥ 3}

Remember: Square brackets include an endpoint; parentheses exclude it. Infinity always uses parentheses.

2. Linear functions

General form: f(x) = mx + b

Example: f(x) = 2x + 1. A nonhorizontal line continues indefinitely in both x and y directions.

DomainRange
All real numbers; (−∞, ∞)All real numbers; (−∞, ∞)

Exception: A constant function, such as f(x) = 3, has domain ℝ but range {3}.

3. Quadratic functions

General form: f(x) = ax² + bx + c, a ≠ 0

Example: f(x) = (x − 2)² − 3. The vertex is (2, −3), and the parabola opens upward.

DomainRange
(−∞, ∞)y ≥ −3; [−3, ∞)

For f(x) = a(x − h)² + k: if a > 0, range is [k, ∞); if a < 0, range is (−∞, k]. Locate the vertex to find the lowest or highest y-value.

4. Absolute value functions

General form: f(x) = a|x − h| + k, a ≠ 0

Example: f(x) = |x + 1| − 2. Its V-shaped graph has vertex (−1, −2).

DomainRange
(−∞, ∞)y ≥ −2; [−2, ∞)

If a > 0, range is [k, ∞). If a < 0, range is (−∞, k]. The vertex determines the minimum or maximum output.

5. Square root functions

Parent function: f(x) = √x

Example: f(x) = √(x − 3) + 2.

Step 1 — Domain: the expression inside the square root must be nonnegative: x − 3 ≥ 0, so x ≥ 3.

Step 2 — Range: √(x − 3) ≥ 0, so y ≥ 2.

DomainRange
x ≥ 3; [3, ∞)y ≥ 2; [2, ∞)

For f(x) = a√(x − h) + k, a ≠ 0: domain x ≥ h; range y ≥ k if a > 0, or y ≤ k if a < 0.

If the radicand is different, the domain can change. For example, √(3 − x) requires x ≤ 3.

6. Cube root functions

General form: f(x) = a∛(x − h) + k, a ≠ 0

Example: f(x) = ∛(x − 2) + 1. Cube roots of negative numbers are real, so the graph extends without input or output bounds.

DomainRange
All real numbers; (−∞, ∞)All real numbers; (−∞, ∞)

9. Five essential rules

  1. Linear: all real inputs and outputs, except constant functions have one output.
  2. Quadratic: the vertex determines the minimum or maximum range value.
  3. Absolute value: the vertex determines the minimum or maximum range value.
  4. Square root: the radicand must be nonnegative; find where the graph starts.
  5. Cube root: all real inputs and outputs are allowed for the standard family.

Key idea: Domain describes allowable x-values; range describes the resulting y-values. Always check the actual equation and any stated restrictions.
