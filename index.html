Inverse Functions Lesson (Terms and Descriptions)

Term Description
Function A rule that assigns each input exactly one output.
Inverse Function A function that reverses the effect of another function.
One-to-One Function A function where different inputs produce different outputs.
Horizontal Line Test A method used to check if a function is one-to-one.
Finding the Inverse The process of swapping variables and solving to reverse a function.
Algebraic Method A step-by-step process used to find the inverse using equations.
Example of Inverse A sample problem that shows how to compute an inverse function.
Verification of Inverse A method of checking if two functions undo each other.
Composition of Functions Applying one function after another.
Graph of Inverse A visual representation showing reflection across the line y = x.
Reflection A flip of a graph across a line, in this case y = x.
Function Without Inverse A function that is not one-to-one and cannot be reversed.
Domain The set of all possible input values.
Range The set of all possible output values.
Domain and Range of Inverse The domain and range switch roles in inverse functions.
Real-Life Application Using inverse functions to reverse processes in real situations.
Practice Exercises Activities to help students apply and understand the concept.
Assessment A test or quiz used to evaluate understanding.
Exponential Function A function where the variable is in the exponent.
Logarithmic Function The inverse of an exponential function.
Composite Function A function formed by combining two functions.
