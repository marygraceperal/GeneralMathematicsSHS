📖 Quick Reference: Formulas & Spreadsheet Instructions

Target Value Mathematical / Calculator Formula Spreadsheet Function (Excel / Google Sheets)
Future Value (\(F\))
(Savings/Investments)		 \[ F = R \left[ \frac{(1 + i)^n - 1}{i} \right] \] =FV(rate_per_period, nper, -pmt)
Example: =FV(0.06/12, 36, -5000)
Present Value (\(P\))
(Loan Principal)		 \[ P = R \left[ \frac{1 - (1 + i)^{-n}}{i} \right] \] =PV(rate_per_period, nper, -pmt)
Example: =PV(0.08/12, 24, -12000)
Periodic Payment (\(R\))
(Loan Repayment)		 \[ R = \frac{P \cdot i}{1 - (1 + i)^{-n}} \] =PMT(rate_per_period, nper, -pv)
Example: =PMT(0.09/4, 20, -500000)
