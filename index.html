✨ Inverse Functions: Terms & Meanings ✨

📘 Term 💡 Description
📌 Function A rule that assigns each input exactly one output.
🔁 Inverse Function A function that reverses the effect of another function.
🎯 One-to-One Function Different inputs produce different outputs.
📏 Horizontal Line Test Used to check if a function is one-to-one.
🔄 Finding the Inverse Swapping variables and solving to reverse a function.
🧮 Algebraic Method A step-by-step way to find the inverse using equations.
🔢 Example of Inverse A sample problem showing how to compute an inverse.
✔️ Verification Checking if two functions undo each other.
🔗 Composition Applying one function after another.
📉 Graph of Inverse Graphs reflect across the line y = x.
🪞 Reflection A flip of a graph across a line.
⚠️ No Inverse Functions that are not one-to-one cannot be reversed.
📥 Domain All possible input values.
📤 Range All possible output values.
🔀 Domain & Range Swap Inputs and outputs switch roles in inverse functions.
🌍 Real-Life Use Used to reverse processes like conversions.
📝 Practice Exercises to build understanding.
📊 Assessment Tests or quizzes to check learning.
📈 Exponential Function A function where the variable is in the exponent.
📉 Logarithmic Function The inverse of an exponential function.
🔗 Composite Function A function formed by combining two functions.
